# GHST3D — Graham Childers Portfolio

Static portfolio website for `ghst3d-dev.com`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload all files in this folder.
2. In the repository, open **Settings → Pages** and choose the branch/folder containing `index.html`.
3. Add `ghst3d-dev.com` under **Custom domain**.
4. At your domain provider, configure the DNS records GitHub gives you.
5. Enable HTTPS after the domain is verified.

GitHub Pages supports custom domains and static HTML/CSS/JavaScript hosting.

## Before publishing

Replace `YOUR_EMAIL_HERE` in `index.html` with Graham's actual professional email.

Also review all experience/certification wording and add exact dates, institutions, credential numbers, resume PDF, LinkedIn, GitHub, and other links when ready.
